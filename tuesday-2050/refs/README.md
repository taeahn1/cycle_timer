# refs/ — 인물 레퍼런스 (절대 규칙)

여기에 주인공 본인 사진 **10장**을 넣어주세요 (`.jpg` / `.png` / `.webp`).

- 모든 컷은 이 사진들에서 **새로 생성**됩니다. 생성 이미지를 재편집하지 않습니다.
- 나이 변환/실사 스펙은 `scripts/generate-cuts.mjs` 및 `src/config.ts`에 이미 반영되어 있습니다.
- 사진이 준비되면: `GEMINI_API_KEY` 환경변수를 설정하고 `npm run gen` 실행.

이 폴더는 커밋되지 않습니다 (개인 사진 보호를 위해 `.gitignore` 처리).
